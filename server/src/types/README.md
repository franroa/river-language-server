# Grafana Alloy Types Scraper

This directory contains a Python script that scrapes type information from the Grafana Alloy documentation.

## Files

- `scrape_types.py` - Main scraping script
- `alloy_types.json` - Extracted type information (generated by the script)
- `README.md` - This documentation file

## Usage

Run the scraper script to fetch and extract type information:

```bash
python3 scrape_types.py
```

The script will:
1. Fetch the latest documentation from https://grafana.com/docs/alloy/latest/get-started/configuration-syntax/expressions/types_and_values/
2. Extract information about:
   - Basic value types (number, string, bool, array, object, function, null)
   - Naming conventions (any, map(T), list(T), duration)
   - Special types (secrets, capsules)
   - Duration format specifications
3. Save the extracted data to `alloy_types.json`
4. Display a summary of the extracted information

## Output

The script generates a JSON file (`alloy_types.json`) with the following structure:

```json
{
  "basic_types": {
    "number": "Any numeric value, such as 3 or 3.14.",
    "string": "A sequence of Unicode characters representing text...",
    // ... other basic types
  },
  "naming_conventions": {
    "any": "A value of any type.",
    "map": "An object where all values are of type T...",
    // ... other conventions
  },
  "special_types": {
    "secrets": "A secret is a special type of string...",
    "capsules": "A capsule is a special type that represents..."
  },
  "duration_formats": {
    "valid_units": [
      {"unit": "h", "description": "hours"},
      // ... other units
    ],
    "combination_example": {
      "original": "\"1h30m\" is",
      "equivalent": "\"90m\""
    }
  }
}
```

## Purpose

This scraper was created to help resolve LSP (Language Server Protocol) issues where the system was incorrectly flagging valid duration strings like "336h" as errors. The extracted type information can be used to improve type validation and provide better IntelliSense support for Grafana Alloy configuration files.

## Dependencies

- Python 3.6+
- requests
- beautifulsoup4

Install dependencies:
```bash
pip install requests beautifulsoup4
```
